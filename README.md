# Crop Doctor

Crop Doctor is a college project designed to help farmers and agricultural users upload plant or crop images and detect the overall health of the plant. The platform aims to make crop monitoring easier by identifying visible signs of disease, stress, or poor health from images.

## Project Goal

The main objective of this project is to provide a simple web-based tool that allows users to:

- upload images of crops or plants
- analyze visual health indicators
- detect possible diseases or stress conditions
- get a quick health assessment for better crop management

## Why this project matters

Healthy crops are essential for food security and sustainable agriculture. Many farmers and growers identify crop issues too late, which can reduce yields. This project helps by providing an accessible image-based tool that gives a faster preliminary health evaluation.

## Features

## How to Run Locally

From the project folder, run:

```bash
cd /Users/kaleemullahkhan/Downloads/crop-doctor
python3 -m http.server 8000
```

Then open this in your browser:

```text
http://localhost:8000/
```

## GitHub Pages Deployment

This project can be hosted using GitHub Pages for public access.

1. Push the repo to GitHub.
2. Go to repository Settings.
3. Open Pages.
4. Select the main branch and root folder.
5. Save.

Your site will be available at:

```text
https://kaleemullah19.github.io/crop-doctor/
```
